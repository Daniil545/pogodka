# Погодка

Telegram Mini App с прогнозом погоды для любого города.

- Настоящие данные: [Open-Meteo](https://open-meteo.com) (бесплатно, без ключа)
- Поиск города, недавние города, моё местоположение
- Прогноз на 24 часа и на 10 дней, предупреждения о ветре, морозе, жаре и гололедице
- Светлая и тёмная тема — как в Telegram

Открыть в Telegram: бот [@poogodka_bot](https://t.me/poogodka_bot), кнопка «Погода».
